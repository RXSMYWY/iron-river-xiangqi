# 铁河棋局

一个基于 Phaser、TypeScript、Node.js 和 Socket.IO 的浏览器中国象棋游戏。

## 游戏模式

- 人机试炼：玩家执红，AI 执黑
- 同屏对战：两名玩家在同一设备轮流落子
- 远程对决：创建房间并通过邀请链接跨设备联机

## 技能象棋

选中己方棋子后，可在左侧“武将技”面板释放技能。每方每种棋子每局限用一次：

| 棋子 | 技能 | 效果 |
| --- | --- | --- |
| 将/帅 | 王令 | 本次走棋后仍由己方继续行动 |
| 士/仕 | 护驾 | 与己方将帅交换位置并结束回合 |
| 象/相 | 山河阵 | 在前方生成一回合不可进入的阻挡 |
| 马 | 破阵 | 本次马步无视蹩马腿 |
| 车 | 战车冲阵 | 本次吃子可以越过一个棋子 |
| 炮 | 烽火标记 | 自动标记同线最近敌人，本次可无炮架攻击 |
| 兵/卒 | 背水一战 | 过河后本次可以斜向前走 |

释放技能时会播放技能音效，并使用浏览器中文语音朗读技能名。

## 声音与视觉反馈

- 音效与语音均使用 `public/audio/` 内的本地 MP3，通过 `HTMLAudioElement` 播放
- 不同棋种拥有不同战争音效和中文落子语音
- 吃子、将军、胜利和重要棋子阵亡有分级音效
- 最后落子位置显示持续脉冲的白色光环
- 浏览器需要允许声音，首次点击棋盘后才能正常播放
- 可通过右上角“声效 ON/OFF”统一控制音效和语音

音频目录：

```text
public/audio/sfx/       火炮、破空、重击等战争音效
public/audio/voice/     棋子、技能、开局与战术语音
public/audio/LICENSES.md
```

可直接用同名 MP3 替换现有文件以更换声音，不需要修改代码。音频授权和生成方式见
`public/audio/LICENSES.md`。

## 名招识别

系统会根据实际落子和局面识别招式，同时显示大字题名并播放对应语音：

- 开局：仙人指路、飞相局、当头炮、起马局、过宫炮、士角炮
- 控制：绊马腿、拦相腰
- 杀法：马后炮、重炮、卧槽马、铁门栓、双车错、小鬼坐龙庭、白脸将

开局名称主要在前几个回合识别，杀法名称只有在形成对应将军局面时触发。

## 对局控制

- 总倒计时：开局前在左侧输入分钟数
- 单步时限：开局前输入每步允许的秒数
- 超时：总时间或单步时间任一归零即判负
- 悔棋：人机与同屏模式直接回退；远程模式需要对手确认
- 求和：同屏模式现场确认；远程模式需要对手确认
- 远程模式的计时、技能、悔棋和和棋均由服务器同步

建议先设置时间，再点击“重开战局”“开始同屏对战”或“创建房间”。

## 本地运行

要求 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

生产模式：

```bash
npm run build
npm start
```

默认地址为 `http://localhost:3001`。

## 为什么不能只用 GitHub Pages

GitHub Pages 只能托管静态文件，不能持续运行 Node.js 和 Socket.IO
房间服务器。因此，只上传到 GitHub Pages 无法支持远程联机。

正确方式是：

1. 将项目上传到 GitHub 仓库。
2. 使用 Render、Railway、Fly.io 或其他 Node.js 平台连接该仓库。
3. 平台同时运行前端静态资源和 Socket.IO 服务。
4. 将部署后的 HTTPS 地址发给玩家。

## 使用 Render 部署

项目包含 `render.yaml`，可以直接使用 Render Blueprint：

1. 在 GitHub 创建仓库并上传项目。
2. 登录 [Render](https://render.com/)。
3. 选择 `New`，然后选择 `Blueprint`。
4. 连接 GitHub 仓库。
5. Render 会读取 `render.yaml` 并自动构建。
6. 部署完成后打开 Render 提供的 `https://...onrender.com` 地址。
7. 进入“远程对决”，创建房间并复制链接。

两台电脑不需要处于同一局域网，只需要都能访问该公网地址。

Render 免费实例休眠后首次打开可能需要等待几十秒。当前房间保存在服务器内存中，
服务重启后房间会消失，这是正常行为。

当前悔棋历史和计时也保存在服务器内存中，服务器重启后不会保留进行中的对局。

## 手动部署参数

如果平台不读取 `render.yaml`：

- Build Command：`npm ci && npm run build`
- Start Command：`npm start`
- Node.js：20 或更高版本
- 端口：使用平台自动注入的 `PORT`

如平台使用自定义反向代理，需要允许 WebSocket 升级连接。
